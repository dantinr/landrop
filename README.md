# 邻传

邻传是一个通过浏览器聊天、分享图片和传输文件的轻量工具，适合在电脑、手机等多台设备之间临时交换信息。无需安装客户端，也无需注册账号。

## 产品说明

- **实时聊天**：支持修改昵称、查看在线成员和输入状态，显示成员上线、离开提示，用户名后显示 IP 地址。
- **文件传输**：电脑端支持选择或拖拽多个文件上传，查看上传进度、取消上传和下载最近文件。
- **图片分享**：支持粘贴截图发送，图片直接显示在聊天中，并保留下载入口；手机端可从相册选择图片上传。
- **专有聊天室**：可设置房间名称和人数上限，通过邀请链接加入，各房间的消息和文件相互独立。
- **多端使用**：电脑端提供聊天和文件面板；手机端提供聊天及图片上传、预览和下载。

## 使用方法

### 打开页面

在浏览器中打开 [邻传](https://icloud.aicsi.cn)，等待页面显示连接成功后即可使用。局域网使用时，让设备连接同一网络，再打开服务提供的局域网地址，例如 `http://192.168.0.10:8787`。

直接打开首页进入公共房间；收到邀请链接时，打开链接进入对应的专有聊天室。

### 发送消息

在页面顶部修改“我的昵称”，在聊天输入框中输入文字，点击发送按钮或按 **Enter** 发送，按 **Shift+Enter** 换行。点击在线人数可查看当前成员。

聊天区的“清空当前显示”按钮仅清空当前页面中的消息显示。

### 上传和下载文件

在电脑端，将文件拖入右侧上传区域，或点击“选择文件”，可一次选择多个文件。上传时可以查看进度或取消；完成后，其他设备可从聊天中的文件卡片或“最近文件”下载。

单个文件最大 **20 MB**（20 × 1024 × 1024 字节），多个文件分别计算大小。手机端仅提供图片上传和图片消息下载，不显示普通文件消息与桌面文件面板。

### 发送截图和图片

- **粘贴截图**：截图后点击聊天输入框，按 **Ctrl+V**（macOS 为 **⌘V**），图片会立即上传，无需先保存为文件，输入框中已有的文字会保留。
- **电脑上传图片**：像普通文件一样选择或拖拽图片上传。
- **手机上传图片**：点击输入框左侧的图片按钮，从相册选择一张或多张图片。支持图片粘贴的浏览器也可在输入框中长按粘贴。

图片上传完成后会直接在聊天中显示，下方保留文件名、大小和下载按钮。浏览器不支持的图片格式或预览失败时，可下载后查看。

### 创建和邀请加入聊天室

1. 点击聊天区右上角的“创建聊天室”按钮，填写房间名称和人数上限。
2. 点击“创建并在新标签页打开”，新房间会在新标签页中打开，原聊天窗口保留。如果浏览器拦截，请允许弹出窗口后重试。
3. 在新房间中点击“复制邀请链接”，将链接分享给需要加入的人。

人数上限包含房主，同一浏览器的多个标签页共用一个名额。房间满员时，可等待成员离开后点击“重试进入”。

房主可点击“销毁聊天室”并确认，删除该房间的聊天记录和上传文件，原邀请链接随即失效。请使用创建房间时的同一浏览器和网站地址管理房间；清除网站数据或更换浏览器后，不会自动保留房主权限。

### 聊天记录和发送额度

每个房间默认保留最近 **20 条**聊天记录，具体条数以页面提示为准。文字、图片和文件卡片合计计算；成员离开房间后，其消息会自动移除。同一浏览器打开多个标签页时，全部离开该房间后才会触发清理。

消息卡片被移除后，已上传的文件仍可从电脑端“最近文件”下载；专有聊天室被销毁时，其中的文件也会删除。

每日发送额度以页面显示为准。启用上限时，文字、文件和图片共用额度，每条文字或每个成功上传的文件、图片计一次，失败或取消的上传不计入。额度在北京时间每天零点重置，切换房间或清理消息不会恢复额度。
